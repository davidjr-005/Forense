
### 2. **Contenido del fichero**
- Breve descripción  
- Captura si aplica  
- Si el contenido no puede mostrarse por seguridad, mostrar hash o encabezado

### 3. **MAC Times** (Modificación, Acceso, Creación)
- Fechas relevantes del artefacto  
- Explicar su relevancia para reconstruir la línea temporal  

### 4. **Tamaño lógico del fichero**
En bytes.

### 5. **Hash criptográfico**
- SHA-256 (preferido)  
- Debe usarse para verificar la integridad del vestigio
